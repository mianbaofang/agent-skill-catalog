# Release notes: agent-skill-catalog v0.4.0

Date: 2026-11-12

v0.4.0 highlights: preserve existing animated project previews, an interactive
catalog UI, and offline-first use.

## Install

Primary stable install, pinned to this release:

```powershell
gh skill install mianbaofang/agent-skill-catalog agent-skill-catalog --pin v0.4.0 --agent codex --scope user
```

The `main` branch remains available as the current source for contributors and
maintainers. A default build is **not** guaranteed offline; add the offline flags
below when the library must stay off the network.

## What changed for users

These changes are present in the current source and covered by the test suite:

- **Preserve existing animated previews.** When preview evidence is available, the
  build keeps complete animated GIF/WebP bytes and the generated viewer animates
  them. This is preservation of existing project animations, not generation of new
  ones. A static SVG category cover is generated only when no preview evidence is
  available, and gallery figures are captioned with their provenance so a generated
  placeholder is never presented as a Skill-specific screenshot.
- **Offline-first preview.** Build a readable catalog from explicit local
  `SKILL.md` roots with `--no-github-discovery --no-github-images`. Missing
  Chinese descriptions stay pending and are not a failure in the default Preview
  build.
- **Optional enriched completion.** When you explicitly ask for full Chinese
  descriptions, add `--require-complete-descriptions` and complete the resumable,
  Agent-owned description queue. Success is exit code 0 **and**
  `pending_description_count == 0`; exit code 3 means that mode is not finished
  yet, not that the tool crashed.
- **Honest offline serving and deletion default.** The catalog serves correctly
  while offline, and Skill deletion stays off unless it is explicitly enabled.
- **Desktop search and detail usability.** The catalog is a desktop-first
  interface. Search, category filtering, and the detail view are laid out for
  comfortable reading and scanning on a desktop screen.
- **Interactive detail entries.** Open a record's detail dialog from its card
  cover, its title, or its action button; each reaches the same native detail
  view.
- **Copy invocation.** The detail dialog has a copy-invocation button. Where the
  browser blocks clipboard access (for example on a `file://` open, or without a
  user gesture), the button reports the failure honestly instead of claiming
  success.
- **Image provenance captions.** Every detail-gallery figure is captioned with its
  provenance, so a generated category placeholder is never presented as a
  Skill-specific screenshot.
- **Public demo guide.** The public demo page injects a compact, collapsible guide
  banner above the product UI. It is collapsed by default and its buttons drive the
  demo's own search, mode, category, and detail controls. This banner is specific
  to the public demo page, not a feature of every generated catalog page.
- **Synthetic demo.** A reproducible synthetic demo catalog preserves same-name
  Skill collisions and shows a curated family and plugin grouping.
- **Bilingual task guides.** Three bilingual task guides cover the primary install
  path, offline builds, and cross-folder skill and plugin inventories.
- **CI and Pages gates.** Every Skill script and repository tool is compiled in CI
  from the directories that hold them; the demo recorder is syntax-checked and
  demo/documentation reproducibility is verified on every push and pull request.
  The GitHub Pages site deploys only after the test suite passes and the committed
  demo and documentation are confirmed reproducible, and Pages publishing plus
  identity-token permissions are limited to the deploy job.

## Boundaries

- The build does not install, execute, or edit scanned Skills. Scanned roots are
  read-only for scanning, building, image selection, and refresh.
- The only source-writing feature is an explicit, opt-in localhost-server deletion
  of one top-level standalone Skill. It runs only when the serving config marks
  that root `allow_delete: true` and the full Skill name is confirmed, and it is
  disabled by default in every shipped config. Family and plugin entries are
  excluded.
- Network is opt-out, not opt-in. Without the offline flags, a build may search
  GitHub by Skill name, verify candidate repositories, and read public repository
  pages and images. The description queue additionally reads one README excerpt per
  queue item; that read is part of the queue and is disabled by its own separate
  flag (`--no-github-readmes`), not by the build call alone. These reads may reuse
  an existing `gh`/token login and never store credentials.
- Search is substring matching over names, descriptions, GitHub metadata, and
  source-relative paths, not semantic search.
- The generated catalog interface is currently Chinese; repository documentation
  is English and Chinese.
- The description queue validates Agent-written Chinese copy. These Python scripts
  never call a hidden model or require a provider key.

## Showcase: moving preview

The public demo now shows the moving-preview capability through one real public
reference record, `agent-skill-catalog`, carried as a local animated GIF
(400x225, 12 frames, 238,457 bytes). The scanner reports it as `verified-local`
and preserves the raw bytes; it is **not** an automatic GitHub README fetch — the
preview manifest sets `not_auto_fetch: true`. The animation is derived from the
project's own earlier public promo animation (source sha256 `42252ac…`), so it is
a documentation-derived snapshot of an existing project animation, not a newly
generated one.

The demo catalog holds 9 individual Skill records (7 standalone-root records and
2 plugin members), presented as 5 Skill/family cards plus 1 plugin aggregate. Of
the 9 individual records, 1 uses the verified-local animated preview and the other
8 stay on generated fallback covers, each captioned with its provenance so a
generated placeholder is never presented as a Skill-specific screenshot.

The completed [Chinese](../media/agent-skill-catalog-demo.v0.4.0.gif) and
[English-captioned](../media/agent-skill-catalog-demo.en.v0.4.0.gif) walkthroughs
are each 22.6 seconds at 960×540 and 5 fps, below 8 MiB per file. They were
produced with a huashu-motion GSAP/OM composition that reframes genuine
built-in-browser footage of the catalog, including the moving reference preview,
detail, zoom, copy invocation, search, and plugin view. The composition was
recorded in the built-in browser and encoded with FFmpeg. See the
[capture manifest](../media/capture-manifest.v0.4.0.json) for provenance, output
metrics, verification limits, and the known brief source-caption artifact. The
[editable source excerpt](../media/motion-v0.4.0/) excludes runtime dependencies
and captured frames.
