# Release notes: agent-skill-catalog v0.5.0

Date: 2026-11-13

v0.5.0 highlights: covers taken from each Skill's own files, automatic grouping
for Skills installed from one repository, sourced public introductions, and
uniform landscape previews.

## Install

Primary stable install, pinned to this release:

```powershell
gh skill install mianbaofang/agent-skill-catalog agent-skill-catalog --pin v0.5.0 --agent codex --scope user
```

The `main` branch remains the current source for contributors and maintainers.
A default build is **not** guaranteed offline; add the offline flags below when
the library must stay off the network.

## What changed for users

- **Use each Skill's own images first.** Cover discovery reads the Skill's
  frontmatter, sidecar files, and its local README (Markdown and HTML) before
  asking GitHub for anything. GitHub is queried only for entries that still have
  no local image. Original GIF and WebP bytes are preserved, so animated previews
  stay animated.
- **Uniform landscape previews.** Every card cover and detail image sits in a
  16:9 frame with the whole original visible (`contain`). Portrait Skills keep
  their complete image inside the landscape frame instead of producing a ragged
  grid.
- **Group Skills from one repository.** Standalone Skills installed from the same
  GitHub repository become one family even when their names share no prefix.
  Plugins remain in their own view, and a manual family override still wins.
- **Sourced public introductions.** With `description_queue.py next --web-research`,
  the invoking Agent searches public pages for a Skill. The applied description
  keeps the source URL, title, retrieval date, and identity evidence, and the
  detail dialog renders them as clickable links. Offline previews never trigger
  research; a missing match keeps the local description.
- **Honest fallbacks.** When neither the local files nor GitHub provide an image,
  the generated category cover stays explicitly labelled. No new AI cover is
  invented and no source image is converted to landscape.

## Fixes

- Repository inference no longer mistakes an installer repository mentioned in a
  README for the Skill's own source; an explicit source label or a unique
  `git clone` URL wins.
- The invocation text no longer renders `SKILL.md 的 SKILL.md`; a standalone
  Skill shows `按 SKILL.md 执行`, and plugin subskills keep their full install
  path.

## Verification

- The full suite passes (157 tests), including new coverage for local README
  previews, same-repository families, sourced introductions, the installer/source
  distinction, and the invocation text.
- The committed demo is regenerated by `tools/build_demo.py` and verified by
  `--check`.
- README screenshots are new stills from the committed offline demo.

## Limits

- Public-introduction research is performed by the invoking Agent; the Python
  tool validates structure and persists sources but cannot independently prove a
  source was opened.
- The demo remains synthetic fixtures plus one real public reference. It is
  offline and reproducible.
- This release does not generate new cover art, convert source images to
  landscape, or publish anyone's private installed inventory.
