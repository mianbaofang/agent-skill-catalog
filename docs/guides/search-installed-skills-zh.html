任务教程

搜索你已经安装的 Agent Skills

你记得装过某个能干这活的工具，却想不起名字，也不知道它放在哪个目录。这篇教程带你选定一个明确的根目录、生成目录、搜索，并打开那个能告诉你怎么调用、来自哪里的条目。

需要 Python 3.10+ · 从仓库根目录运行 · 阅读英文版

开始之前

你需要先确认 Skill 实际所在的文件夹路径。Agent Skill Catalog 不会替你猜这个路径，它只扫描你明确给出的根目录。不同 Agent 和不同安装方式会把 Skill 放到不同位置，你也可能自定义过目录，所以下面出现的路径只是需要你自行核对的示例，不是固定默认值。

  • 一个包含若干 Skill 子文件夹的目录，每个子文件夹里有一个 SKILL.md。
  • 用于运行构建器的 Python 3.10 或更高版本。
  • 下面命令都从仓库根目录执行，所以请先克隆或下载本项目。

关于路径。 如果你用 gh skill install ... --agent codex --scope user 安装过 Skill，它会被放到该 Agent 的用户作用域。扫描前请先在自己的系统上确认确切目录。下文刻意使用占位路径。

第 1 步：从一个根目录生成目录

把 /path/to/skills 换成你确认过的文件夹，把 /path/to/catalog-output 换成一个空输出文件夹。下面这些参数让首次构建完全离线。

Bash（macOS、Linux、Windows Git Bash）

python skills/agent-skill-catalog/scripts/build_catalog.py \
  --root "/path/to/skills" \
  --output-dir "/path/to/catalog-output" \
  --no-github-discovery \
  --no-github-images

PowerShell（Windows）

python skills/agent-skill-catalog/scripts/build_catalog.py `
  --root "C:\path\to\skills" `
  --output-dir "C:\path\to\catalog-output" `
  --no-github-discovery `
  --no-github-images

预期结果。 退出码 0，输出文件夹里出现 catalog.json 和自包含的 index.html。这条命令没有加 --require-complete-descriptions，所以中文说明还没补齐的条目也会显示，你可以立刻浏览和搜索。

第 2 步：按名称、说明或路径搜索

用浏览器打开 index.html，在搜索框输入内容。当前搜索是对 Skill 名称、说明、GitHub 信息和来源相对路径做子串匹配，随后可以按分类或视图筛选。可以搜一个你记得一部分的名字，例如 skill-catalog，或者搜一个你确定出现在某条说明里的词。

预期结果。 列表收窄到匹配字段包含该子串的条目。搜索确切名称 agent-skill-catalog 会返回那一张卡片。

这是什么搜索。 它是对名称、说明和来源路径的字面子串匹配，不是语义搜索或自然语言搜索，也不会给“哪个 Skill 最适合这个请求”排序。一个只存在于你的意图里、没有出现在任何名称、说明或路径中的词，不会命中。

第 3 步：打开条目查看调用方式

点击结果卡片打开详情视图。这个面板正是目录的价值所在，它会显示：

  • 调用方式，让你能用正确的说法向 Agent 提出请求。
  • 来源位置，也就是生成该条目的那份 SKILL.md 的相对路径。
  • 分类候选与置信度，分类不确定时会保留复核标记。
  • 本地或包证据支持时的 GitHub 仓库链接；证据不足时显示 missing evidence。

拿到调用文案后，你就可以在下次会话里按名字让 Agent 使用该 Skill。

多个根目录，以及下次换目录

把 --root 重复多次，就能在一次构建里扫描多个根目录。安装新 Skill 后要重新扫描，用同样的 --root 和 --output-dir 再跑一遍同一条命令。如果输出文件夹已经存在，构建器会拒绝替换并报错退出；确认目标文件夹里是可重新生成的目录后，再加 --refresh 重跑。把某个根目录标记为插件缓存的做法见跨目录清点 Skill 与插件。

排错

现象可能原因与处理
目录为空，或只有一个不相关条目--root 指向的目录下，子文件夹没有各自包含 SKILL.md。检查路径，改指向容纳各个 Skill 文件夹的父目录。
提示找不到命令请从仓库根目录运行，让相对路径 skills/agent-skill-catalog/scripts/build_catalog.py 能解析，并确认 python --version 是 3.10 或更高。
条目的说明为空或缺失快速预览下这是正常的。追加 --require-complete-descriptions 进入离线生成 Skill 目录里描述的补全流程。
本想离线构建，却看到 GitHub 活动只有同时给出 --no-github-discovery 和 --no-github-images，首次构建才是离线的。漏掉任一参数都会允许一次 GitHub 请求。
