# Acknowledgements

Agent Skill Catalog is an independent open-source project. It follows the public [Agent Skills specification](https://agentskills.io/specification) and uses Python's standard library for scanning, deterministic JSON generation, HTML rendering, and the localhost-only refresh server.

The README screenshots and animation are created from the catalog UI and original explanatory graphics using non-personal local test data. Those test Skill records are not included in the repository or the installable package. No private prompts, private Skill files, or personal catalog data are included.

GitHub, Codex, OpenAI, Anthropic, and all Skill, plugin, provider, and repository names shown by a user's local scan remain the property of their respective owners. Their appearance in a catalog is metadata, not sponsorship or endorsement.
